## Color palette

Three scales, 50–900, defined in `tailwind.config.js`. Swatches use literal class names —
Tailwind can't JIT-compile a class assembled from a template string, so each step is spelled
out rather than interpolated.

export const PALETTE = {
  brand: ["bg-brand-50", "bg-brand-100", "bg-brand-200", "bg-brand-300", "bg-brand-400", "bg-brand-500", "bg-brand-600", "bg-brand-700", "bg-brand-800", "bg-brand-900"],
  accent: ["bg-accent-50", "bg-accent-100", "bg-accent-200", "bg-accent-300", "bg-accent-400", "bg-accent-500", "bg-accent-600", "bg-accent-700", "bg-accent-800", "bg-accent-900"],
  ink: ["bg-ink-50", "bg-ink-100", "bg-ink-200", "bg-ink-300", "bg-ink-400", "bg-ink-500", "bg-ink-600", "bg-ink-700", "bg-ink-800", "bg-ink-900"]
};

export const STEPS = [50, 100, 200, 300, 400, 500, 600, 700, 800, 900];

<div className="grid grid-cols-3 gap-6 my-4">
  {Object.entries(PALETTE).map(([scale, classes]) => (
    <div key={scale}>
      <p className="mb-2 text-xs font-semibold uppercase tracking-wide text-ink-700">{scale}</p>
      <div className="flex flex-col gap-1">
        {classes.map((cls, i) => (
          <div key={cls} className={`flex items-center gap-2 rounded-lg ${cls} px-2 py-1`}>
            <span className="text-[10px] font-mono text-black/60 mix-blend-multiply">{scale}-{STEPS[i]}</span>
          </div>
        ))}
      </div>
    </div>
  ))}
</div>

Two hardcoded neutrals sit outside the scale and drive most surfaces: `#0b0a0e` (near-black —
primary buttons, active nav state) and `#ffffff` (all card/surface backgrounds).

## Shape rule

A global override in `src/index.css` forces every `button`, `[role="button"]`, `.btn-primary`
and `.btn-secondary` to `border-radius: 0.75rem` regardless of Tailwind rounding classes —
this is why buttons across the app share one corner radius even when a component author reaches
for `rounded-full`.
